# Code of Conduct

We want Chroma to be a welcoming project for everyone. Be kind, be patient, assume good intent,
and keep criticism about code, not people. Harassment, discrimination and personal attacks are not
tolerated in issues, pull requests or any project space.

Maintainers may remove comments or contributions that break these rules and may block repeat
offenders. Report problems privately to the maintainer via a GitHub security advisory or the email
on the maintainer's profile.

This code is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
