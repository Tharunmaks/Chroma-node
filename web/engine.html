Helix engine

The 3D studio. Materials are Pyre.

Everything below runs on Helix in your browser. Pick a scene, swap materials (each one is a Pyre program compiled to GLSL on the fly), or drop in your own .glb model.

API at a glance

Set up
import { Helix, Models, createDNA } from 'helix';

const engine = new Helix(canvas, {
  bloom: true,        // or { strength, radius, threshold }
  autoRotate: true,   // orbit controls are on by default
  camera: [0, 0, 6],
});
engine.add(createDNA());
engine.start();   // renders only while visible
Pyre materials
const mat = engine.material(pyreSource, {
  uniforms: { tint: [1, 0.4, 0.2] },
});
// time, resolution and mouse are fed automatically
mat.set('glow', 2.0);
const r = mat.setSource(newSource);   // hot-swap
if (!r.ok) console.log(r.message);    // old shader keeps running
Models
const knot = engine.mesh(Models.torusKnot(), mat);
const robot = await engine.load('robot.glb', { fit: 3 });
const mine = await engine.load(fileFromDragAndDrop);
engine.add(knot, robot);
Animation
engine.onFrame((t, dt) => {
  knot.rotation.y = t * 0.4;
  knot.position.x = engine.pointer.x;  // smoothed -1..1
});
engine.enableBloom({ strength: 0.8 });
const png = engine.screenshot();
